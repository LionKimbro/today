# Visual language

Today is a calm, nocturnal workspace built from layers of darkness:

```text
app → header → card → control
```

| role | color |
| --- | --- |
| app | `#081522` |
| header | `#0C1D2E` |
| card | `#102438` |
| control | `#182E45` |
| editor | `#0C1925` |
| border | `#29577F` |
| divider | `#1A3A55` |
| primary text | `#E8EEF7` |
| secondary text | `#9FB4CC` |
| muted text | `#7289A1` |
| blue accent | `#4C9BFF` |
| purple accent | `#A66BFF` |
| green accent | `#65D18A` |

Cards use thin borders only where they carry meaning. Panel accents identify a hosted panel; blue is the primary action color; green marks available/new choices. Standard Tk widgets remain square and conventional—no decorative Canvas machinery for rounded corners.
